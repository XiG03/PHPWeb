## 🔄 Tải lại hình ảnh

Nếu bạn muốn tải lại tất cả hình ảnh (ví dụ: để lấy hình chất lượng cao hơn hoặc hình khác), chạy lệnh:

```bash
npm run download-images
```

Hoặc:

```bash
node download-images.mjs
```

## 📝 Lưu ý

- Tất cả hình ảnh được tải từ Unsplash (miễn phí, không cần attribution cho mục đích thương mại)
- Hình ảnh đã được tối ưu kích thước phù hợp với từng section
- Nếu bạn muốn thay thế bằng hình ảnh từ Figma, chỉ cần thay thế file tương ứng trong thư mục `public/images/`

## 🎨 Thay thế hình từ Figma

Nếu bạn có hình ảnh từ Figma design, bạn có thể:

1. Export hình từ Figma (File > Export > chọn format JPG/PNG)
2. Đặt tên file giống với tên trong danh sách trên
3. Copy vào thư mục `public/images/` để thay thế
